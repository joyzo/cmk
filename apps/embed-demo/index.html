CMK Embed Demo

このデモは @cmk/embed のカスタムエレメント <cmk-embed> を実際に動かして確認するための環境です。 Kintone の接続情報を設定しない場合はモックデータで動作します。

現在のモード: 判定中...

最新記事

使い方

  1. pnpm install を実行
  2. pnpm build でパッケージをビルド
  3. apps/embed-demo/.env.example を参考に接続情報を設定
  4. pnpm dev --filter @cmk/embed-demo で起動

モックモードでの表示例: 

<cmk-embed data-app="blog" data-slug="hello-world"></cmk-embed>
